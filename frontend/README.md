# Angular tenant management

Standalone Angular tenant create/edit/contact forms, authorized list/details, cookie-session authentication and saved/draft branding preview. Approved requirements now enable saves, subscription validation, reference options and backend-derived lifecycle actions. See [approved-rule handoff](../docs/approved-rules.md) for configuration, evidence and limitations.

Use the root [README](../README.md) for shared Docker setup. Native commands: `npm ci`, `npm start`, `npm run build`, `npm test -- --watch=false`. Build output: `dist/frontend`. No e2e runner or lint target is configured.

Member 1 reviews navigation/shared frontend changes; Member 4 reviews forms. Members 2/3 review business/access/migration changes.
